## Engineering Standards
- **Zero-Cloud Client-Side Privacy**: All mathematical computations run purely in the browser; zero client data is transmitted to external servers.
- **Parametric Sensitivity Engines**: Real-time slider recalculation linked to dynamic Chart.js canvases.
- **Regulatory & Accounting Friction**: SFRS(I), IFRS 16, IRAS corporate tax, and jurisdictional statutory compliance integrated into model formulas.
